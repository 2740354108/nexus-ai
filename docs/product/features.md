# 产品需求

## 项目定位

NEXUS LAB 是一个面向品牌/作品展示的高科技风格落地页，用于展示创意团队的能力、精选作品、数据成就和客户评价，吸引潜在客户发起合作咨询。

## 功能特性

### 1. 沉浸式品牌首屏
- 全屏深色科技背景，搭配青色/紫色霓虹光晕与网格纹理
- 大标题采用渐变霓虹文字与发光效果，强化科技感
- 双 CTA 引导用户查看作品或了解团队
- 滚动提示动画，引导用户向下浏览

### 2. 品牌跑马灯
- 无限循环滚动的合作品牌名称墙
- 两侧渐变遮罩，营造沉浸式氛围
- 悬停时品牌名高亮

### 3. 能力/服务展示
- 6 项核心能力卡片：品牌视觉、界面开发、产品策略、AI 应用、全球化体验、安全可靠性
- 每张卡片拥有独立渐变图标与玻璃拟态边框
- 滚动进入视口时渐现，悬停时轻微上浮

### 4. 精选作品集
- 3 个代表项目卡片，展示项目名称、类别、简介
- 卡片顶部采用彩色渐变视觉块
- 悬停显示“查看项目”遮罩

### 5. 数据统计
- 4 个核心数据指标：服务品牌数、客户满意度、行业经验、行业奖项
- 数字滚动动画，进入视口时从 0 增长至目标值

### 6. 客户评价
- 3 条客户/合作伙伴推荐语
- 包含姓名、职位与头像
- 玻璃拟态卡片设计

### 7. 行动号召区
- 醒目 CTA 区块，引导用户预约免费咨询
- 渐变霓虹背景光晕
- 双按钮布局：主 CTA + 查看作品

### 8. 页脚导航
- 品牌简介与社交媒体入口
- 三列服务/公司/资源链接
- 版权与法律条款

## 设计风格

- **主题**：科技动感、深色霓虹、未来感
- **主色调**：深空蓝黑 + 青色/蓝紫色渐变
- **视觉元素**：玻璃拟态、发光阴影、网格背景、浮动光晕、渐变文字
- **动画**：滚动渐现、数字滚动、浮动光晕、按钮悬停、跑马灯
- **字体**：Inter Variable，现代无衬线，大标题负字距
